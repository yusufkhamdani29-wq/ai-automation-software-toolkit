# Business OS — Home

Your one-page home for the week. Link the four databases below, then
start every day here.

## This week

- **Top 3 goals** (edit this list each Monday):
  1. _Goal 1: _________________________________________
  2. _Goal 2: _________________________________________
  3. _Goal 3: _________________________________________

- **Today's focus:** _one task that matters most: _____________________

## Databases

Link each CSV import as a full-page database:

- **Tasks** (`tasks.csv`) — every open and done task, with due date,
  status, and minutes tracked.
- **Clients** (`clients.csv`) — client names, contact, status, and notes.
- **Projects** (`projects.csv`) — projects with status and hourly rate.
- **Invoices** (`invoices.csv`) — invoices with amount, status, and
  date sent. Check this every Friday: anything open 7+ days gets a
  reminder.

## Quick views to build

- **Tasks due this week** — Tasks database, filtered to Due date =
  this week, sorted by date.
- **Open invoices** — Invoices database, filtered to Status = Open,
  sorted by date sent (oldest first).
- **Active clients** — Clients database, filtered to Status = Active.

## Weekly routine

1. **Monday (5 minutes):** pick the top 3 goals and write them above.
2. **Daily:** check "Tasks due this week" and do the first one.
3. **Friday (15 minutes):** run the Weekly Review page
   (`Weekly-Review.md`).
