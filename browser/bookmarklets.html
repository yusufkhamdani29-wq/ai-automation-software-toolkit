Browser Productivity Bookmarklets

Drag a button below to your bookmarks bar. Click it on any page to run it. No data leaves your browser — these run entirely on the page you are viewing.

1. Copy page as Markdown

Copies the page title and URL as a Markdown link, plus any text you have selected as a quote.

Copy as Markdown

2. Text counter

Counts the words and characters of your selected text — or of the whole page if nothing is selected — and shows the result in a small box.

Text Counter

3. Tab title cleaner

Strips the site name from the tab title (everything after " - ", " | ", or " — "), so tabs show the page name first. Run it again to restore the original title.

Clean Tab Title

How to install

  1. Show your bookmarks bar (Ctrl+Shift+B in Chrome/Edge, Ctrl+Shift+B in Firefox).
  2. Drag a button above onto the bar.
  3. Click the bookmark on any page to run it.

The same three bookmarklets are also in bookmarklets.txt as plain text, for pasting into a bookmark by hand.
