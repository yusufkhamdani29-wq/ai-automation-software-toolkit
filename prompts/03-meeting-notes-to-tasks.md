# Workflow 03 — Meeting Notes to Tasks — Never Lose an Action Item

## The problem

Meetings end with pages of notes and nobody remembers who promised what. Action items hide inside paragraphs and deadlines slip.

## What you need

Your meeting notes or a transcript (typed or from a recording transcript) and an AI chat tool.

## Copy-paste prompts

### Prompt 1: Extract the tasks

```
Here are my meeting notes:
[PASTE NOTES]

Extract every action item into a table with four columns: Task | Owner | Deadline | Notes. If the owner or deadline is not stated in the notes, write 'Not stated' — do not guess. Keep each task to one line.
```

### Prompt 2: Write the follow-up email

```
Using the task table above, write a follow-up email to the meeting attendees. Under 150 words. List each person's tasks as bullets. End with the date of the next check-in, or '[DATE]' if it was not decided.
```

## Steps

1. Paste the notes into prompt 1 and check the table against your memory of the meeting.
2. Fill in any 'Not stated' owner or deadline yourself — this is the step AI cannot do.
3. Send the follow-up email from prompt 2 the same day, while the meeting is fresh.
4. Copy the table into your task tracker (the spreadsheet in this toolkit works).

## Tools

Any AI chat tool. A transcript source if you record meetings (your phone's recorder + a transcription app, or your meeting tool's built-in transcript).

## Time saved

Turning notes into a task list by hand takes 20–30 minutes and still misses items. This takes about 5 minutes plus a 2-minute check.
